# ✈️ Travel Website (React)

Este é um projeto de um site de viagens desenvolvido com **React**, com foco na criação de uma interface moderna e interativa para exibição de destinos.

## 🌍 Sobre o projeto

A aplicação apresenta destinos turísticos em formato de cards, permitindo interação do usuário e servindo como prática de conceitos fundamentais do React.

## 🚀 Funcionalidades atuais

* Exibição de destinos em cards
* Componentização com React
* Uso de props para passar dados entre componentes
* Interações básicas (mostrar/ocultar informações)

## 🛠️ Tecnologias utilizadas

* React
* JavaScript (ES6+)
* HTML5
* CSS3

## 📂 Estrutura do projeto

```bash
/src
  ├── components/
  │     └── Card.jsx
  ├── assets/
  ├── App.jsx
  └── main.jsx
```
